# Быстрая настройка Wi-Fi (рекомендуется)

На ноутбуке Windows в PowerShell открой:

```powershell
cd C:\OMA-Vision\oma_be
git pull --ff-only origin feat/full-catalog-visual-index
powershell -NoProfile -ExecutionPolicy Bypass -File .\backend\scripts\setup_oma_wifi.ps1
```

Скрипт автоматически определит IP активного Wi-Fi, настроит разрешение
для порта 8765 **только в локальной подсети на доверенной частной сети**,
проверит SigLIP2 и запустит сервер, если он не работает.

При запросе Windows нажми **Да** для разрешения администраторских изменений.
Если Wi-Fi имеет профиль «Общедоступная», скрипт сначала спросит,
является ли сеть доверенной: введи `YES` только для собственной сети.
Если настройка завершилась успешно, скопируй URL после
`Paste this into OMA Android photo-search settings:` в APK.

В APK **0.15.5**: Главная → Поиск по фото → выбрать фото →
Настроить нейропоиск на ПК → вставить URL → «Проверить подключение и начать поиск».
Приложение должно подтвердить реальный ответ сервера с количеством SKU.

Открой на **телефоне** URL после `Open this link on the PHONE`.
Если там не отображается `ready:true`, компьютер не доступен из Android
(гостевая сеть, изоляция клиентов, VPN, Firewall, неправильная сеть).
Автоматическая настройка ноутбука не может снять изоляцию,
установленную роутером/точкой доступа.

# ОМА: проверка сохранённых ~13–14 тыс. SKU непосредственно в Android

Это **локальный пробный режим** — индексация всех 134 187 SKU не требуется.
Он работает с сохранёнными `vectors.npy` и `metadata.sqlite`, даже если в
`manifest.json` указано `complete: false`. Файлы не модифицируются.
Не запускайте индексатор одновременно с сервером.

## 1. Запусти нейросеть на ПК

В PowerShell:

```powershell
cd C:\OMA-Vision\oma_be
git pull --ff-only origin feat/full-catalog-visual-index
.\.venv-vision\Scripts\python.exe .\backend\scripts\serve_partial_visual_api.py
```

Должно появиться `OMA SigLIP2 demo: ... saved SKU / 134187 total`.
Оставь это окно открытым. Первый поиск может включать загрузку весов модели
из локального Hugging Face кэша.

На том же ПК проверь доступность сервиса во **втором** PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:8765/api/v1/visual-search/status
ipconfig
```

В выводе `ipconfig` найди строку IPv4-адрес активного **Wi-Fi-адаптера**,
например `192.168.1.42`.

## 2. Установи новую APK

Из [GitHub Actions](https://github.com/evander006/oma_front/actions/workflows/visual-search-apk.yml)
скачай артефакт `oma-visual-search-branch-apk` из последней **успешной**
сборки ветки `feat/visual-catalog-sku-ranking`.
Это **отладочная** APK 0.15.4; обычная release-сборка не разрешает
незащищённый HTTP.

Компьютер и Android должны быть подключены к одной доверенной локальной Wi-Fi
сети. На запрос Windows Firewall разрешай входящие соединения **только для
частной сети**; не настраивай проброс портов роутера.

## 3. Один раз укажи адрес нейросети

Открой ОМА → Главная → Поиск по фото → Выбрать из галереи
(или Сделать фото).

На экране с выбранным фото нажми `Настроить нейропоиск на ПК`.
Введи IP своего компьютера с портом `8765`:

```text
http://192.168.1.42:8765
```

Замени пример на реальный IPv4 твоего компьютера. Нажми
`Подключить ПК и проверить фото`.

APK отправит выбранное фото только этому локальному API,
а запросы остальных функций приложения продолжат идти на прежний сервер.

## 4. Проверка

Ожидаем: заголовок `Похожие товары`, изображения из каталога ОМА,
правильные SKU и подпись `Пробный визуальный поиск среди ...`.
Нейросеть перебирает только сохранённые 13–14 тысяч SKU.
Если подходящий товар не вошёл в эту часть каталога, точного совпадения
может не быть.

Для второго телефона повтори шаги 2–3. Сервер обрабатывает одновременно
не более одного GPU-запроса для предотвращения нехватки памяти RTX 4050.

## Если APK не видит сервер

- Убедись, что ПК и телефон подключены к одной Wi-Fi, а не к гостевой сети
  с изоляцией клиентов; телефон не должен быть только на мобильном интернете.
- В браузере на Android открой `http://<IP-ПК>:8765/api/v1/visual-search/status`.
  Если страница не загружается, проверь IP, Windows Firewall и работающий
  PowerShell-сервер.
- `0 товаров` не означает, что отсутствует сервер; сначала смотри статус
  на ПК. Проверь, что в APK показано `Нейропоиск SigLIP2: подключён ПК`.
- Для возвращения к старому серверу нажми `Настроить нейропоиск на ПК`
  → `Вернуться к обычному поиску`.

## Безопасность

Это не production API: сервер доступен без авторизации внутри локальной сети.
Используй только собственные тестовые фотографии на доверенной Wi-Fi, **не
передавай личные данные**, не открывай порт 8765 в интернет.
По окончании демонстрации останови сервер через Ctrl+C.
Обычные запросы прочих функций приложения не перенаправляются на ПК.
